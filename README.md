# マネーナビJP

新NISA・iDeCo・投資・副業の総合マネー情報サイト

## 技術スタック

- Next.js 16.2.2 (App Router)
- React 19.2.4
- TypeScript 5
- Tailwind CSS 4

## 開発

```bash
npm install
npm run dev
```

http://localhost:3000 を開く

## ビルド

```bash
npm run build
```

## デプロイ

Vercelにデプロイ（GitHub pushで自動デプロイ）
